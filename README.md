# AI Hospital Resource Coordination System

An AI-assisted hospital operations and resource coordination system
for simulated hospital environments.

## Goal

The system helps coordinate hospital resources such as:

- Beds
- ICU beds
- Doctors
- Nurses
- Diagnostic equipment
- Emergency capacity

The system generates personalized, explainable operational recommendations
while keeping human decision-makers in the loop.

## Safety Boundary

This project is for hospital operations and resource coordination.

It does not diagnose diseases, recommend medical treatment, or prescribe medication.

The system uses synthetic/simulated data.
